# Danish Startup Community

A terse, lookup-focused reference for startup founders in Denmark. This site covers legal setup, funding, hiring, operations, and community resources specific to the Danish startup ecosystem.

## Live Site

This site is designed to be deployed on GitHub Pages. Once deployed, it will be available at your GitHub Pages URL.

## What's Covered

- **Legal Setup** - Company registration, structures (ApS), foreign founder requirements
- **Funding** - Public grants (Innovationsfonden, Vækstfonden), VCs, angels, accelerators
- **Hiring** - Employment law, compensation, equity, work permits
- **Operations** - Tax (SKAT), VAT, accounting, compliance
- **Service Providers** - Lawyers, accountants, banks, and other services
- **Community** - Meetups, events, online groups
- **FAQ** - Common questions answered

## Key Updates (2026)

- **ApS minimum capital reduced to 20,000 DKK** (from 40,000 DKK, effective Jan 1, 2025)
- **IVS abolished** - No longer available since April 2019
- **Pay Limit Scheme** - 552,000 DKK salary threshold for 2026
- **Innobooster grants** - 200k-5M DKK with up to 35% co-financing
